# Design Brief — دليل التصميم
## منصة حجز ملاعب البادل

---

## 1. الاتجاه التصميمي (Design Direction)

**Premium Sports Club** — هوية بصرية نظيفة، حديثة، وسريعة الإحساس، تعكس طابع رياضي راقٍ وليس بيروقراطيًا.

**كلمات مفتاحية:** Minimal · Premium · Clean · Modern · Fast

---

## 2. نظام الألوان (Color System)

| الاستخدام | اللون | Hex |
|---|---|---|
| Primary (أساسي) | أخضر عميق | `#0E7A53` |
| Primary Light | أخضر فاتح | `#18A777` |
| Background | رمادي فاتح جدًا | `#F5F7F8` |
| Surface | أبيض | `#FFFFFF` |
| Text Primary | رمادي غامق شبه أسود | `#202124` |
| Success | أخضر (نفس Primary Light) | `#18A777` |
| Warning | برتقالي | `#F5A623` |
| Error | أحمر | `#E5484D` |

**الوضع الداكن (Dark Mode):** مدعوم — نفس النظام مع عكس القيم (Background `#121417`, Surface `#1B1E22`).

---

## 3. الطباعة (Typography)

| اللغة | الخط |
|---|---|
| الإنجليزية | Inter |
| العربية | IBM Plex Sans Arabic |

- الحجم الأساسي للنص: 16px، مع مقياس Type Scale متسق (12/14/16/18/24/32/40).
- وزن العناوين: Semi-bold إلى Bold؛ النصوص العادية: Regular/Medium.

## 4. الأيقونات والمسافات (Icons & Spacing)

- **الأيقونات:** Lucide (خفيفة، خطوط موحدة، تدعم RTL تلقائيًا).
- **شبكة المسافات:** 8px grid (كل الـ padding/margin مضاعفات 8).
- **الانحناءات:** Border-radius = 12px للبطاقات والأزرار (نمط ودود، غير حاد).
- **الحركات (Animations):** سريعة وسلسة وخفيفة (150–250ms، easing: ease-out) — لا مبالغة.

---

## 5. دعم اللغتين (i18n / RTL Support)

- تبديل فوري بين العربية (RTL) والإنجليزية (LTR) **بدون إعادة تحميل الصفحة**.
- استخدام CSS logical properties (`margin-inline-start` بدل `margin-left`) لضمان انعكاس صحيح.
- جميع الأيقونات الاتجاهية (أسهم، رجوع/تقدّم) تنعكس تلقائيًا حسب الاتجاه.
- الأرقام: تُعرض بصيغة غربية (١٢٣ vs 123) — يُفضَّل الإبقاء على الأرقام اللاتينية لثبات القراءة في السياق المالي.

---

## 6. الاستجابة (Responsive Breakpoints)

| الجهاز | العرض |
|---|---|
| Mobile | < 640px |
| Tablet | 640–1024px |
| Desktop | > 1024px |

تجربة العميل (Customer flow) مصممة **Mobile-first** لأن الغالبية ستحجز من الجوال. لوحة التحكم (Admin) مصممة Desktop-first مع دعم Tablet.

---

## 7. مكونات أساسية (Key Components)

- **Time Slot Grid:** شبكة أزرار للأوقات المتاحة (متاح / محجوز بصريًا فقط، غير مضغوط).
- **Booking Cart Drawer:** درج جانبي يعرض السلوتات المختارة والمجموع أثناء الحجز.
- **Admin Booking Table:** جدول بفلاتر متعددة + Badges ملوّنة لحالة الحجز (Pending أصفر / Confirmed أخضر / Cancelled أحمر).
- **Court Calendar (Admin):** تقويم أسبوعي يعرض إشغال كل ملعب.
- **Toast Notifications:** لكل عملية ناجحة/فاشلة.
- **Skeleton Loaders:** أثناء تحميل الأوقات المتاحة وقوائم لوحة التحكم.

---

## 8. إمكانية الوصول (Accessibility)

- تباين ألوان يحقق WCAG AA على الأقل (نص/خلفية).
- كل عناصر التفاعل قابلة للوصول عبر لوحة المفاتيح (Tab/Enter).
- Labels واضحة لكل حقول الإدخال + `aria-label` عند الحاجة.
- حالات focus مرئية بوضوح.
